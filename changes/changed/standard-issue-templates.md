# Standardize issue templates and add label automation

Replaces the legacy Markdown issue templates with the org-standard YAML forms, which set a native issue type, `status:untriaged`, and this repo's `component:*` defaults. Adds SHA-pinned dispatchers for the shared label and lifecycle workflows.
