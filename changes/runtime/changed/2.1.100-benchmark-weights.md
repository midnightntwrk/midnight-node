# Regenerate runtime weights for 2.1.100 on the reference machine

Re-runs the full `benchmark pallet` suite against `release/node-2.1.100` on the
mainnet benchmark syncbox (c7i.xlarge, Intel Xeon Platinum 8488C, the same CPU as
the 2.1.0 run) at STEPS=50, REPEAT=20, with the same command line as 2.1.0.

The weights committed for 2.1.0 predate the per-UTXO cursor in
`pallet_cnight_observation` (#56). `process_tokens` now reads
`NextCardanoCursor` instead of `NextCardanoPosition`, `CardanoBlockWindowSize`
and `CardanoTxCapacityPerBlock`, so its storage accounting drops from five reads
to three; the regenerated file reflects that.

Everything else moved within run-to-run variance (median 0.93x of the previous
base weights across 136 functions). The 2.1.0 hand fix-ups are carried over:
`::weights::WeightInfo` paths for the three pallets that export it there, the
hand-written GRANDPA `report_equivocation`, the upstream `pallet_safe_mode`
deposit weights, and the Council instance for `pallet_collective` and
`pallet_membership`.
