# Update Rust toolchain to 1.100.0

Updates Rust from 1.98.1 to 1.100.0 across all components: the workspace
`rust-toolchain.toml`, the `subxt` and nightly cNIGHT e2e container base
images, and the srtool image used for deterministic runtime WASM builds
(`ghcr.io/shieldedtech/srtool:1.100.0-0.18.6`).

The runtime WASM is rebuilt by a new compiler, so its hash changes even though
the runtime source does not.

Clippy 1.100 now lints code generated by `#[frame_support::pallet]` and
`derive(new)` (`clone_on_copy`, `redundant_field_names`,
`duplicated_attributes`), so those lints are allowed on each pallet module and
on the two `derive(new)` inherent-data structs. Hand-written code is unchanged
apart from dropping a deprecated `core::u32` import and new rustfmt output.

Also sets cargo 1.100's `registry.global-min-publish-age = "7 days"` in
`.cargo/config.toml`, matching dependabot's cooldown: new resolutions skip crate
versions published in the last week (versions already in `Cargo.lock` are kept).

`[workspace.lints.cargo]` now denies cargo 1.100's `unused_dependencies` and
`unused_workspace_dependencies` (removing an unused `midnight-node-toolkit`
workspace dependency and `sidechain-mc-hash`'s unused `derive-new`). The CI image
now bakes in npm, `perl-Digest-SHA`, `cargo-hack` 0.6.46 and `cargo-shear` 1.6.6
(its tag gains `-npm<version>`), so CI jobs no longer reinstall them per run.
